# Release preparation

This repository is a private development version. Registry publication is disabled.

Before a public release:

1. Confirm the release name and repository metadata.
2. Select a license and add its complete license text and manifest metadata.
3. Verify the remote repository visibility and repository/homepage/issue URLs.
4. Run all documented checks, including integration tests and executable examples.
5. Review public APIs, changelog, supported versions and package contents.
6. Remove the manifest publication guard only when preparing the release.
7. Tag the reviewed commit and publish using the registry's normal authenticated workflow.

No credentials or real customer data belong in examples, fixtures or documentation.
